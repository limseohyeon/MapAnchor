# MapAnchor — 사용자 매뉴얼

이 글은 **컴퓨터나 프로그래밍을 잘 모르셔도** 따라 하실 수 있도록 작성했습니다.  
위에서부터 **번호 순서대로** 진행하세요. 앞 단계를 건너뛰면 다음 단계에서 오류가 날 수 있습니다.

> **팁**  
> - 화면에 나오는 글자를 **그대로 복사**해 붙이세요.  
> - 한 번에 많이 하지 말고, **한 단계가 끝나면** 다음으로 넘어가세요.  
> - 중간에 막히면 맨 아래 **「자주 생기는 문제」**를 먼저 보세요.

---

## 이 프로그램으로 할 수 있는 일

1. 지도 도면 파일(`.dwg` 또는 `.dxf`)을 올립니다.
2. 화면에 도면이 보입니다.
3. 주소를 검색하면, 도면 위에 위치가 표시됩니다.

처음 한 번만 아래 설치·설정을 해 두면, 이후에는 **실행 파일만 더블클릭**하면 됩니다.

---

## 1. 준비물

시작 전에 아래가 있는지 확인하세요.

| 준비물 | 설명 |
|---|---|
| Windows 컴퓨터 | 이 매뉴얼은 Windows 기준입니다. |
| 인터넷 | 설치 파일·프로그램을 받을 때 필요합니다. |
| 프로젝트 압축 파일 | 전달받은 `.zip` 파일입니다. |
| (주소 검색을 쓸 경우) 카카오 계정 | 카카오톡/카카오 로그인이 되는 계정입니다. |
| (선택) 도면 파일 | 테스트용 `.dwg` 또는 `.dxf` 파일 |

---

## 2. 압축 풀기

1. 전달받은 `.zip` 파일을 **마우스 오른쪽 클릭**합니다.
2. **압축 풀기** 또는 **모두 추출**을 선택합니다.
3. 위치를 고릅니다.  
   추천: `문서` 폴더 안  
   예: `문서\MapAnchor`
4. 풀린 폴더를 엽니다.
5. 안에 다음 이름들이 보이면 정상입니다.
   - `run_app.bat`
   - `requirements.txt`
   - `frontend` 폴더
   - `backend` 폴더
   - `scripts` 폴더
   - `tools` 폴더 (DWG를 쓸 때 ODA 설치 파일이 들어 있습니다)

이 폴더 위치를 기억해 두세요. 다음 단계에서 이 폴더로 들어갑니다.

---

## 3. Python 설치

이 프로그램을 돌리려면 **Python**이라는 기본 프로그램이 필요합니다.  
(한 번만 설치하면 됩니다.)

1. 인터넷 브라우저에서 [Python 다운로드 페이지]( https://www.python.org/downloads/ )를 엽니다.
   **3.11** 또는 **3.12** 버전이면 충분합니다.
3. 받은 파일을 실행합니다.
4. 설치 화면 **맨 아래**에 있는 항목을 **반드시 체크**합니다.  
   **Add python.exe to PATH**  
   (이 칸을 빼먹으면 나중에 오류가 납니다.)
5. **Install Now**를 눌러 설치를 끝냅니다.
6. 설치가 되었는지 확인합니다.
   1. 키보드에서 `Windows 키`를 누릅니다.
   2. `PowerShell`이라고 입력한 뒤 **Windows PowerShell**을 엽니다.
   3. 아래 글을 복사해 창에 붙이고 `Enter`를 누릅니다.

```text
python --version
```

7. `Python 3.11...` 또는 `Python 3.12...`처럼 **숫자**가 보이면 성공입니다.

숫자가 안 나오고 오류가 나면, Python을 삭제한 뒤 **4번(PATH 체크)**을 다시 확인하며 재설치하세요.

## 4. 프로그램에 필요한 부품 설치

압축을 푼 폴더 안에서, 프로그램이 쓰는 **추가 부품**을 한 번 설치합니다.  
인터넷이 연결된 상태에서 진행하세요. **시간이 몇 분 걸릴 수 있습니다.**

### 4-1. 폴더에서 명령 창 열기

1. 탐색기에서 **2번에서 푼 폴더**를 엽니다.  
   (`run_app.bat`이 보이는 그 폴더입니다.)
2. 폴더 **빈 곳**에서 `Shift` 키를 누른 채 **마우스 오른쪽 클릭**합니다.
3. **PowerShell 창에서 열기** 또는 **터미널에서 열기**를 선택합니다.  
   (메뉴 이름이 PC마다 조금 다를 수 있습니다.)

검은(또는 파란) 글씨 창이 열리면 됩니다.

### 4-2. 아래 명령을 한 줄씩 실행

창에 **한 줄씩** 복사해 붙인 뒤, 매번 `Enter`를 누르세요.  
앞 줄이 끝날 때까지 기다리세요. (글씨가 많이 흘러가도 정상입니다.)

**① 작업 공간 만들기**

```text
python -m venv .venv
```

**② 설치 도구 최신화**

```text
.\.venv\Scripts\python.exe -m pip install --upgrade pip
```

**③ 프로그램 부품 설치** (가장 오래 걸릴 수 있습니다)

```text
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

모두 끝난 뒤, 다시 입력할 수 있는 상태가 되면 성공입니다.  
폴더 안에 `.venv`라는 새 폴더가 생겨도 정상입니다. **지우지 마세요.**

## 5. ODA 설치 (DWG 파일을 쓸 때만)

- 올릴 파일이 **`.dxf`만**이면 → 이 장은 **건너뛰어도** 됩니다.
- 올릴 파일이 **`.dwg`**이면 → 반드시 설치하세요.

DWG 파일은 프로그램이 바로 읽지 못하고, **ODA File Converter**라는 변환 프로그램이 필요합니다.  
홈페이지에서 따로 받을 필요 없습니다. 프로젝트 안의 `tools` 폴더에 설치 파일(`.msi`)이 들어 있습니다.

### 5-1. 설치 파일 확인

1. 압축을 푼 폴더를 엽니다.
2. `tools` 폴더를 엽니다.
3. 아래와 비슷한 이름의 파일이 있는지 확인합니다.  
   `ODAFileConverter_....msi`  
   (이름이 조금 달라도, 끝에 `.msi`이면 됩니다.)

`tools` 폴더가 없거나 `.msi` 파일이 없으면, 전달받은 압축 파일에 설치 파일이 빠진 것입니다. 다시 받으세요.

### 5-2. 설치하기 (더블클릭)

1. `ODAFileConverter_....msi` 파일을 **더블클릭**합니다.
2. 설치 화면이 나오면 안내대로 **Next / Install**을 눌러 설치를 끝냅니다.
3. 설치가 끝나면 보통 프로그램이 알아서 ODA를 찾습니다.

### 5-3. 설치하기 (PowerShell — 화면 없이 설치)

더블클릭이 안 되거나, 화면 없이 설치하고 싶을 때 씁니다.

1. 압축을 푼 폴더(`MapAnchor` 등)에서 빈 곳을 `Shift` + 오른쪽 클릭합니다.
2. **터미널에서 열기** 또는 **PowerShell 창 여기서 열기**를 선택합니다.
3. 아래를 **한 줄 그대로** 붙여 넣고 `Enter`를 누릅니다.  
   (`MapAnchor` 부분은 **본인 폴더 경로**로 바꿉니다. `tools` 안의 `.msi` 이름도 실제 파일명과 같게 맞춥니다.)

```text
msiexec /i "C:\Users\내이름\Documents\MapAnchor\tools\ODAFileConverter_QT6_vc16_amd64dll_27.1.msi" /qn ALLUSERS=2 MSIINSTALLPERUSER=1 REBOOT=ReallySuppress /l*v "C:\Users\내이름\Documents\MapAnchor\tools\oda-install.log"
```

4. 몇 초~수십 초 뒤 다시 입력할 수 있는 상태가 되면 설치가 끝난 것입니다.  
   확인용으로 `tools\oda-install.log` 파일이 생겼는지도 볼 수 있습니다.

나중에 도면 상태가 **차단** 또는 **blocked**로 나오면, 이 장의 설치가 안 되었거나 프로그램을 찾지 못한 경우입니다.  
그때는 아래 **「자주 생기는 문제」**의 “변환이 안 되고 차단(blocked)으로 나옴”을 보세요.

## 6. 주소 검색용 카카오 키 넣기

도면 위에 **주소로 위치**를 찍으려면 카카오에서 발급하는 **키(비밀번호 같은 문자열)**가 필요합니다.  
주소 검색을 쓰지 않으면 이 장은 건너뛰어도 됩니다.

### 6-1. 키 받기

1. 브라우저에서 [카카오 개발자]( https://developers.kakao.com/ )에 접속합니다.
2. 카카오 계정으로 로그인합니다.
3. **내 애플리케이션** → **애플리케이션 추가하기**로 앱을 하나 만듭니다.  
   (이름·회사명은 본인이 알아볼 수 있게만 적어도 됩니다.)
4. 만든 앱을 연 뒤 **앱 키** 메뉴에서 **REST API 키**를 찾습니다.
5. 키를 **복사**해 메모장 등에 잠시 붙여 둡니다.  
   (다른 사람에게 공유하지 마세요.)

### 6-2. 프로그램에 키 넣기

1. 탐색기에서 **2번에서 푼 폴더**를 엽니다.
2. `.env.example` 파일을 찾습니다.  
   (이름 맨 앞에 점 `.`이 있습니다. 안 보이면 탐색기 위쪽 **보기**에서 **숨긴 항목** 또는 **파일 이름 확장명**을 켜 보세요.)
3. 그 파일을 **복사**한 뒤, 같은 폴더에 붙여 넣습니다.
4. 복사본 이름을 `.env`로 바꿉니다.  
   - 바꾸기 전 예: `.env.example - 복사본`  
   - 바꾼 뒤: `.env`  
   - 이름 맨 앞의 점(`.`)을 지우면 안 됩니다.
5. `.env` 파일을 메모장으로 엽니다.  
   (파일 위 오른쪽 클릭 → **연결 프로그램** → **메모장**)
6. 아래처럼 **REST API 키**만 넣습니다.  
   `=` 뒤에 바로 붙이고, 따옴표(`"`)는 넣지 않습니다.

```text
KAKAO_REST_API_KEY=여기에_복사한_키를_붙여넣기
```

7. **저장**하고 메모장을 닫습니다.

키를 바꾼 뒤에는 프로그램이 실행 중이면 **완전히 끈 다음** 다시 실행해야 적용됩니다.

## 7. 프로그램 실행하기

설치·설정이 끝나면 실행은 간단합니다.

1. 푼 폴더에서 `run_app.bat` 파일을 **더블클릭**합니다.
2. 검은 창이 열리고 글씨가 잠시 지나갑니다. **이 창을 닫지 마세요.**
3. 잠시 후 인터넷 브라우저가 자동으로 열리고, 프로그램 화면이 나옵니다.  
   주소는 보통 `http://localhost:8501` 입니다.
4. 브라우저가 안 열리면, 브라우저 주소창에 아래를 직접 입력해 보세요.

```text
http://localhost:8501
```

### 종료하는 방법

- 검은 창을 클릭한 뒤 `Ctrl` + `C`를 누르거나,
- 검은 창의 **X(닫기)**를 누릅니다.

검은 창을 닫으면 프로그램도 함께 꺼집니다.

## 8. 사용 방법

브라우저 화면에서 아래 순서로 사용합니다.

### 8-1. 도면 올리기

1. 화면에서 파일을 올리는 버튼을 찾습니다.
2. `.dwg` 또는 `.dxf` 파일 **한 개**를 선택합니다.
3. 업로드가 끝날 때까지 기다립니다.

### 8-2. 변환 기다리기 (DWG인 경우)

- **`.dxf`**: 바로 사용할 수 있는 경우가 많습니다.
- **`.dwg`**: 변환이 끝날 때까지 기다립니다. 큰 파일은 시간이 더 걸립니다.
- 상태가 **차단** / **blocked**이면 → **5장 ODA 설치**와 아래 문제 해결을 확인하세요.

### 8-3. 도면 보기

1. **내 도면** 목록에서 올린 도면을 선택합니다.
2. 변환이 끝나면 DXF 도면 뷰어에 바로 내용이 보입니다.  
   (서버가 PNG로 변환하지 않고, 변환된 DXF를 바로 표시합니다.)  
   같은 도면을 다시 열면 브라우저 캐시·압축 덕분에 이전보다 빠르게 열릴 수 있습니다.
3. 목록 상태가 **주소 준비 중**이면 도면은 볼 수 있고, 주소 검색용 도면 범위만 아직 준비 중입니다.  
   큰 도면도 헤더·스트리밍 방식으로 범위를 빠르게 잡도록 되어 있습니다.

### 8-4. 좌표계·도면 단위

도면에 맞는 **좌표계**를 고른 뒤 저장합니다.  
도면을 열 때 **도면 단위(미터 / 밀리미터)** 가 자동으로 잡히기도 하고, 맞지 않으면 화면 위쪽에서 직접 바꿀 수 있습니다.

좌표계나 단위가 도면과 다르면, 나중에 찍는 주소 위치가 어긋날 수 있습니다.

### 8-5. 주소 검색

1. 목록 상태가 **준비됨**이 되면 주소 검색을 사용할 수 있습니다.  
   (범위 준비가 끝나기 전에는 검색 칸이 잠시 비활성입니다.)
2. 도로명 주소 또는 지번 주소를 입력하고 검색합니다.
3. 도면 범위 **안**이면 위치에 표시(마커)가 생깁니다.
4. 범위 **밖**이면 안내 문구가 나오고, 억지로 찍히지는 않습니다.
5. 주소를 여러 번 검색하면 표시가 **계속 쌓입니다.**  
   브라우저 화면을 끄거나 프로그램을 종료하면 표시는 사라집니다. (다시 저장되지는 않습니다.)

### 8-6. 도면 삭제

목록에서 필요 없는 도면을 삭제할 수 있습니다.  
삭제하면 이 컴퓨터에 저장된 해당 도면도 함께 지워집니다.

## 9. 자주 생기는 문제

### “Python 환경을 찾지 못했습니다”가 나옴

1. **4장**을 처음부터 다시 진행했는지 확인합니다.  
   특히 `.venv` 폴더가 생겼는지 봅니다.
2. 그래도 안 되면, **4-1**처럼 PowerShell을 연 뒤 아래를 입력합니다.  
   (`MapAnchor` 부분은 **본인 폴더 경로**로 바꿉니다.)

```text
$env:DWG_MAP_PYTHON = "C:\Users\내이름\Documents\MapAnchor\.venv\Scripts\python.exe"
```

3. 같은 창에서 `run_app.bat`을 실행하거나, 탐색기에서 `run_app.bat`을 다시 더블클릭합니다.

### 부품 설치(4장) 중에 빨간 오류가 남

1. 인터넷이 연결되어 있는지 확인합니다.
2. **4-1**처럼 폴더에서 PowerShell을 다시 엽니다.
3. 아래만 다시 실행합니다.

```text
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

4. 계속 실패하면 Python을 **3.11** 또는 **3.12**로 다시 설치한 뒤, **4장**을 처음부터 다시 합니다.

### 실행했는데 화면이 안 열리거나, “포트가 사용 중”이라고 나옴

1. 예전에 실행해 둔 프로그램이 남아 있을 수 있습니다.
2. `run_app.bat`을 한 번 더 실행해 봅니다.
3. 그래도 안 되면:
   1. `Ctrl` + `Shift` + `Esc`로 **작업 관리자**를 엽니다.
   2. 목록에서 `Python`이 보이면 선택 후 **작업 끝내기**를 합니다.
   3. 다시 `run_app.bat`을 실행합니다.

### DWG 변환이 안 되고 차단(blocked)으로 나옴

1. **5장**에서 `tools` 안의 `.msi`로 ODA를 설치했는지 확인합니다.
2. 설치했는데도 같으면, 프로그램을 완전히 종료한 뒤 다시 실행합니다.
3. 계속 안 되면, PC에 설치한 `ODAFileConverter.exe` 위치를 찾아 `.env` 파일에 한 줄을 추가합니다.  
   더블클릭 설치 시 보통 아래와 비슷한 위치입니다. (`내이름`, 버전 숫자는 PC에 맞게 바꿉니다.)

```text
ODA_FILE_CONVERTER_PATH=C:\Users\내이름\AppData\Local\Programs\ODA\ODAFileConverter 27.1.0\ODAFileConverter.exe
```

경로를 넣는 방법: `ODAFileConverter.exe`를 찾은 뒤, 파일을 `Shift` + 오른쪽 클릭 → **경로로 복사**한 내용을 `=` 뒤에 붙입니다.

### DWG 변환이 실패(failed)로 나옴

1. 파일이 깨지지 않은 정상 `.dwg`인지 확인합니다.
2. 컴퓨터 저장 공간(디스크)이 충분한지 확인합니다.  
   큰 도면은 변환할 때 공간을 많이 씁니다.
3. 다른 DWG로 한 번 더 시험해 봅니다.

### 주소가 검색되지 않음

1. **6장**에서 `.env` 파일을 만들었는지 확인합니다.
2. `KAKAO_REST_API_KEY=` 뒤에 키가 **실제로** 들어 있는지 확인합니다. (빈칸이면 안 됩니다.)
3. 키를 넣은 뒤 프로그램을 **완전히 종료했다가** 다시 실행했는지 확인합니다.
4. 카카오 개발자 사이트에서 키가 정상인지 다시 확인합니다.
